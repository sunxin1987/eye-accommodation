# 人眼成像调节模拟

眼球的角膜和晶状体共同作用，相当于一个**焦距可调的凸透镜**；视网膜相当于固定不动的光屏。拖动蜡烛（或点预设按钮），看晶状体怎样变厚变薄、把远近不同的物体都成像在视网膜上。

在线打开：https://sunxin1987.github.io/eye-accommodation/

## 能做什么

- **调节模拟**：蜡烛可拖（物距 10 cm–6 m），自动调焦时睫状肌收缩/舒张、悬韧带松紧、晶状体厚薄和瞳孔大小联动变化；也可切换手动调焦自己找焦点。
- **眼睛状态**：正常眼 / 近视眼（眼轴过长）/ 远视眼（眼轴过短）/ 老花眼（调节力弱），缺陷眼可佩戴对应度数的矫正眼镜（凹透镜 −350 度、凸透镜 +300/+250 度），像落在视网膜前/后时出现模糊光斑和「视网膜上的像」预览。
- **读数**：物距、所需焦距、当前焦距、焦度、近点/远点，公式带入数值实时显示；下方有看远看近对照表、缺陷眼成因与矫正、水透镜实验对照。
- **演示**：一键播放「物体由远到近」。

参考：B 站《可变焦凸透镜（水透镜）模拟人眼成像》https://b23.tv/5CVDuqf —— 水透镜注水变厚、焦距变短（看近物）；抽水变薄、焦距变长（看远物）。

## 手机安装

- **Android**：下载 Releases 里的 `eye-accommodation.apk`，直接安装（WebView 封装，离线可用）。
- **iOS**：下载 Releases 里的 `eye-accommodation.ipa`（未签名），在 iPhone 上用 [AltStore](https://altstore.io) 打开安装，需配合电脑上的 AltServer；免费账号签名的 App 每 7 天过期，iPhone 与电脑同一 WiFi 且 AltServer 开着时自动续签。
